# Leafs
Dans un serveur classique, tous les coûts sont partagés. Leafs découpe le monde en régions indépendantes, et chaque région vit son propre tick à 20 TPS. Leafs ajoute le multithreading, et rien d'autre. Aucune feature de gameplay, aucune API. Les optimisations RAM/CPU sont faites dans un mod séparé, Mapple, qui fonctionne sans ou avec Leafs.
